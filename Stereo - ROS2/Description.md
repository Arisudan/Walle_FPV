| **Sensor**           | **What it captures**                                                                                                                                 | **Stream name**                        | **Resolution / Rate**                                |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- | ---------------------------------------------------- |
| **RGB Camera**       | Regular color image                                                                                                                                  | `RS2_STREAM_COLOR`                     | Up to **1920 × 1080 @ 30 FPS**                       |
| **Left IR Camera**   | Infrared grayscale image                                                                                                                             | `RS2_STREAM_INFRARED` (Index **1**)    | Up to **1280 × 720 @ 90 FPS**                        |
| **Right IR Camera**  | Infrared grayscale image                                                                                                                             | `RS2_STREAM_INFRARED` (Index **2**)    | Up to **1280 × 720 @ 90 FPS**                        |
| **IR Projector**     | Projects an infrared dot pattern onto the scene. It is **not a data stream**; it helps the stereo cameras find matching points for depth estimation. | —                                      | —                                                    |
| **Depth (Computed)** | Depth map generated by comparing the left and right IR images (stereo disparity). This is **not a raw sensor**.                                      | `RS2_STREAM_DEPTH`                     | Up to **1280 × 720 @ 90 FPS**                        |
| **IMU (BMI055)**     | Motion sensing data (the **"i"** in D435i). Provides linear acceleration and angular velocity measurements.                                          | `RS2_STREAM_ACCEL` + `RS2_STREAM_GYRO` | Accelerometer: **~250 Hz**<br>Gyroscope: **~400 Hz** |

## Frames and Data Available in Code

When using the Intel RealSense D435i SDK, you can access the following data streams:

| **Data Stream**        | **Description**                                                                                            | **Output**                              |
| ---------------------- | ---------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| **Color Frame**        | Standard RGB image, similar to a webcam.                                                                   | 3-channel color image                   |
| **Depth Frame**        | A matrix where each pixel stores the distance from the camera.                                             | Depth values (typically in millimeters) |
| **Infrared Frames**    | Raw left and right grayscale IR images. Useful for low-light operation, SLAM, and debugging depth quality. | Two grayscale images                    |
| **Accelerometer Data** | Measures linear acceleration along the X, Y, and Z axes.                                                   | **m/s²**                                |
| **Gyroscope Data**     | Measures angular velocity around the X, Y, and Z axes.                                                     | **rad/s**                               |
